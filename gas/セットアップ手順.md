# みまもり（GAS版）セットアップ手順

古いスマホのサーバーを使わず、**Googleの上で見守りを動かす**ための手順です。
用意するもの：Googleアカウント1つだけ。パソコンでもスマホでもできますが、**パソコン推奨**です。

---

## 第1部：ひな形を作る（西さんが1回だけ）

### 1. スプレッドシートを新しく作る
Googleドライブ → 新規 → Googleスプレッドシート。名前を「**みまもり**」にします。

### 2. スクリプトを貼る
メニューの **拡張機能 → Apps Script** を開きます。
最初から入っている `function myFunction() {}` を**全部消して**、`コード.gs` の中身を丸ごと貼り付け、保存（Ctrl+S）。

### 3. メニューを出す
スプレッドシートのタブに戻って、**ページを再読み込み**します。
上のメニューに「**みまもり**」が増えていれば成功です。

### 3.5 ⏰ タイムゾーンを確認する（ふつうは日本になっています）

念のための確認です。ここがずれていると、締め切り時刻がその分だけずれます。

1. Apps Scriptの画面の**左側にある歯車マーク（プロジェクトの設定）**をクリック
2. 「**タイムゾーン**」が **(GMT+09:00) 日本標準時 - 東京** になっているか見る
3. スプレッドシート側も「**ファイル**」→「**設定**」→「タイムゾーン」が **(GMT+09:00) 東京** か見る

どちらも東京ならそのままで大丈夫です。**両方を同じにしておく**ことだけ守ってください。

> このスプレッドシートをコピーして配ると、タイムゾーンの設定も一緒に複製されます。
> ひな形の側を正しくしておけば、受け取った人は設定し直さなくて済みます。

### 4. 初期設定を1回目（シートを作らせる）
「みまもり」→「**① 初期設定**」をクリック。

ここで **承認画面**が出ます。⚠️ **一番の関門です。**

1. 「承認が必要です」→ **権限を確認**
2. 自分のGoogleアカウントを選ぶ
3. **「このアプリはGoogleで確認されていません」**という赤っぽい警告が出ます
   → 左下の「**詳細**」→「**（安全ではないページ）に移動**」
4. 「許可」

> **なぜこの警告が出るのか**：Googleに審査を出していない自作スクリプトだからです。
> 中身は自分で貼ったコードなので問題ありません。ただし**詐欺の画面と見分けがつかない**ので、
> 他の人に配るときは必ずこの画面のスクショを手順書に入れてください。ここで9割が止まります。

承認が終わると「連絡先メールを先に入力してください」と出て、シートが4枚作られます。

### 5. 「設定」シートを埋める

| 項目 | 例 | 説明 |
|---|---|---|
| 見守る方のお名前 | 太郎 | メールの文面に入ります |
| 連絡先メール（家族） | you@example.com | ここに通知が届きます |
| 締め切り時刻 | 10:00 | この時刻までに押されないと通知 |
| 毎日の報告メール | する | **「しない」にしないでください**（下の注意参照） |
| 熱中症の警戒を出す | する | ボタン画面に暑さの注意を出す |
| お住まいの都道府県 | 愛知県 | 暑さを調べるのに使う |

### 6. 初期設定をもう1回
「みまもり」→「① 初期設定」。今度は最後まで進みます。

- 15分おきの見張りが仕掛けられます
- 連絡先に「見守りを開始しました」メールが届きます ← **届いたら成功**

### 7. ウェブアプリとして公開する
右上の **デプロイ → 新しいデプロイ**。

1. 歯車マーク →「**ウェブアプリ**」を選ぶ
2. 説明：`v1`（何でもいい）
3. **次のユーザーとして実行：自分**
4. **アクセスできるユーザー：全員** ← ここ重要。ログインなしで親が押せるようにするため
5. デプロイ → 出てきた **ウェブアプリのURL をコピー**

このURL（`https://script.google.com/macros/s/…/exec`）が、ボタン画面から呼ぶ先になります。

> ⚠️ **コードを直したら、「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→ デプロイ** を
> やらないと反映されません。ここは間違えやすいところです。

### 8. 動作確認
「みまもり」→「**② テスト通知を送ってみる**」で、実際にメールが届くか確かめます。
「③ いまの状態を見る」で、見張りが動いているかを確認できます。

## 第2部：人に配るとき

### コピー用リンクの作り方
スプレッドシートの共有URLの、末尾の `/edit#gid=0` の部分を **`/copy`** に書き換えるだけです。

```
https://docs.google.com/spreadsheets/d/XXXXXXXX/copy
```

このリンクを開いた人には「**コピーを作成**」ボタンが出ます。押すと、**スクリプトごと**その人のドライブに複製されます。

### 相手にやってもらうこと
1. リンクを開いて「コピーを作成」
2. 「みまもり」→「① 初期設定」（例の警告を1回越える）
3. 「設定」シートに名前とメールを入力
4. もう一度「① 初期設定」
5. 「デプロイ」→「新しいデプロイ」→ ウェブアプリ →「全員」→ URLをコピー
6. そのURLをボタン画面の設定に貼る

**5がいちばん難しい**ので、スクショ必須です。

### ここが大事：データは相手のものになります
コピーした人のスプレッドシートに記録が入り、**その人のGmailから**メールが出ます。
西さんは他人の安否データもメールアドレスも一切持ちません。止めるのも消すのも相手の自由です。

## 分かっている制約（先に知っておくこと）

| 制約 | 中身 |
|---|---|
| **通知は最大15分遅れる** | 見張りは15分おきなので、10:00締切なら通知は10:00〜10:15の間 |
| **URLを知る人は誰でも押せる** | 「アクセス：全員」のため。URLは推測できないが、SNS等に貼らないこと |
| **Gmailの送信上限** | 無料アカウントで1日100通。1人あたり日に1〜2通なので余裕 |
| **承認の警告が出る** | 上の第1部4を参照。配布時の最大の壁 |
| **コード修正後は再デプロイが要る** | 保存だけでは反映されない |

## 毎日の報告メールを切らないでください

見守りアプリの最悪の壊れ方は「**黙って止まること**」です。
止まったのに何も届かないと、家族は「通知が来ない＝元気なんだな」と思い込みます。

毎日1通「きょうも元気です」が届いていれば、**メールが来ること自体がこの仕組みが生きている証明**になります。
届かない日は「本人か、この仕組みのどちらかに何かあった」と分かる。
だから、うるさく感じても報告メールは切らない設計にしてあります。
