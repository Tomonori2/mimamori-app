# みまもり

毎日ボタンを押すだけ。押されなかった日に、家族へ自動でメールが届きます。

**ボタン画面 → https://tomonori2.github.io/mimamori-app/**

離れて暮らす親の安否確認を、**月額0円**でやるための道具です。
専用の機械もサーバーも要りません。記録と見張りとメール送信は、
**利用者ご自身のGoogleアカウント**の中で動きます。

---

## できること

- 大きなボタンで「元気です／ふつうです／しんどい」を伝える
- 締め切り時刻までに押されないと、家族へ **「合図がありません」** メール
- 遅れて押されたら **「無事でした」** メール
- 毎日1回 **「きょうも元気です」** メール
- 暑い日は熱中症の警戒を画面に表示（気象データはOpen-Meteo・APIキー不要）
- ボタンを押した**場所**を記録し、メールに地図のリンクを付ける（切ることもできます）
- スマホのホーム画面に置ける（PWA）

> **📍 場所について、はっきりさせておきます**
>
> 記録されるのは、**ボタンを押したその瞬間**の場所だけです。
> ブラウザで動くアプリは、画面が閉じている間に居場所を追いかけることはできません。
>
> ですから「合図がありません」のお知らせに出る場所は、
> **最後に押したときの場所**であって、いま現在いる場所ではありません。
> ここを取り違えると判断を誤るので、メールの本文にも同じ但し書きを入れてあります。
>
> 場所のデータが入るのは、**利用者ご自身のスプレッドシートの中だけ**です。
> 設定で「しない」を選べば、記録も表示もされません。

## 大事な考え方：毎日の報告メールは切らないでください

見守りの仕組みで一番こわいのは、**黙って止まること**です。
止まったのに何も届かないと、家族は「通知が来ない＝元気なんだな」と思い込みます。

毎日1通「きょうも元気です」が届いていれば、**メールが来ること自体が
この仕組みが生きている証明**になります。届かない日は
「本人か、この仕組みのどちらかに何かあった」と分かる。
うるさく感じても、報告メールは切らない設計にしてあります。

## 仕組み

```
  📱 ボタン画面（このページ・PWA）
        │  押す
        ▼
  ⚙️  Google Apps Script     … 判定する・メールを出す
        ▲▼
  📊 スプレッドシート          … 設定と記録の保管庫
        │
  ⏰ 15分おきに自動で見張り
        └→ 合図がなければ → 📧 家族へ
```

- **データは利用者自身のGoogleアカウントの中**にあります。作者は何も預かりません
- ボタン画面にウェブアプリのURLを貼る方式なので、**このコードに個人情報は入りません**

## 使いはじめかた

[gas/セットアップ手順.md](gas/セットアップ手順.md) を見てください。

準備するもの：Googleアカウント1つと、**パソコン**（最初の1回だけ）。
ボタンを押す側はスマホだけで大丈夫です。

おおまかな流れ：

1. スプレッドシートを作り、[gas/コード.gs](gas/コード.gs) を Apps Script に貼る
2. 「みまもり」メニュー →「① 初期設定」（Googleの承認を1回通す）
3. 「設定」シートに名前・連絡先メール・締め切り時刻を入れる
4. ウェブアプリとしてデプロイし、出てきたURLをこのページの設定に貼る
5. スマホでこのページを開き、ホーム画面に追加する

## 分かっている制約

- 通知は最大15分遅れます（見張りが15分おきのため）
- 最初の設定にはパソコンが必要です（スマホのスプレッドシートではメニューが出ません）
- 承認のときに「このアプリはGoogleで確認されていません」という警告が出ます
- URLを知っている人は誰でもチェックインできます。SNS等に貼らないでください
